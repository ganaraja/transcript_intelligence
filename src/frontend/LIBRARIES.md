# React libraries

Installed with **npm** in `src/frontend`.

## Runtime (`package.json` dependencies)

| Package | Why |
| --- | --- |
| react, react-dom | UI |
| react-router-dom | Overview / Themes / Sentiment / Graph / Accounts / meeting routes |
| @tanstack/react-query | API fetch + cache |
| recharts | Pie, stacked bars, weekly sentiment lines |
| react-force-graph-2d | Cross-surface issue network |
| lucide-react | Header icon |

## Dev (`npm install -D`)

| Package | Why |
| --- | --- |
| vite | Dev server + build |
| @vitejs/plugin-react | React compiler plugin |
| typescript | Types |
| tailwindcss, @tailwindcss/vite | Layout and dark theme |
| oxlint | Lint script from the Vite template |

Exact versions: `src/frontend/package-lock.json`.
